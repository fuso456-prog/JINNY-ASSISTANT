# Preferences

## Work style & energy patterns

_Last updated: 2026-09-02_

- **Peak energy:** Afternoon — best window for deep work.
- **Work style:** Prefers deep, uninterrupted blocks over short sprints or task-juggling.
- **Energy drains:** Unclear/open-ended tasks (no clear definition of "done"), and too many small tasks piling up (admin/busywork).

**Implications:**
- Schedule/suggest demanding or deep-focus work for the afternoon; keep mornings for lighter/admin tasks if possible.
- When handing off work or defining tasks, be explicit about what "done" looks like — avoid leaving scope open-ended.
- Batch small tasks together rather than letting them scatter; flag when busywork is piling up so it can be cleared in one pass.
