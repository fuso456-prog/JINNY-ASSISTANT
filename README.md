# Jinny

This folder is Jinny's home base — your personal assistant workspace.

## Files

- [TASKS.md](TASKS.md) — running to-do list (active / done)
- [NOTES.md](NOTES.md) — general notes, ideas, reference info
- [JOURNAL.md](JOURNAL.md) — dated journal entries
- [context/admin/preferences.md](context/admin/preferences.md) — work style & energy patterns
- [context/admin/daily-notes/](context/admin/daily-notes/) — daily notes, organized by year/month

## How this works

Just talk to Jinny normally. Ask to add a task, jot a note, or log a journal
entry, and it'll get written to the right file above. Nothing here is rigid —
structure can change as needs change.
